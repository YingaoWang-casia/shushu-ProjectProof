# Role: 算法 / 推荐 / 搜索 / 机器学习

适用：推荐算法、搜索排序、广告、NLP/CV、机器学习、深度学习、数据挖掘。

## 大厂看重点

- 能讲清问题定义、数据、特征、模型、指标、实验、误差分析。
- 不是只“跑模型”，要有 baseline、对比、消融、bad case 和上线思考。
- 能解释指标为什么可信，是否有数据泄漏，离线提升是否可能线上无效。

## Toy 感

- 只写“使用 CNN/Transformer/LightGBM 提升准确率”。
- 没有数据来源、划分、特征、baseline。
- 没有消融实验、误差分析、bad case。
- 指标没有口径，可能训练/测试泄漏。
- 没有推理延迟、资源、线上服务考虑。

## 可补强动作

半天：

- 补任务定义：输入、输出、标签、指标。
- 补 baseline 和数据划分说明。
- 整理 10 条 bad case：误分类、长尾、冷启动、噪声样本、极端 query。

1 天：

- 增加指标表：baseline vs 改进方案。
- 补混淆矩阵、错误样例、特征重要性。
- 检查数据泄漏和随机种子。

3 天：

- 做消融实验：去掉某类特征、换模型、换参数。
- 增加推理耗时和资源统计。
- 做简单 demo/API 展示推理结果。

1 周：

- 增加离线评估流水线、实验记录和可复现配置。
- 设计线上 A/B 或灰度方案。
- 增加特征监控、数据漂移、模型版本管理。

## 八股和场景题

算法项目常被转问基础题。优先结合 `algorithm-depth-question-bank.md` 和 `scenario-bagua-drills.md` 训练。

### 数据相关

- 缺失值怎么处理？删除、填充、单独编码有什么风险？
- 异常值怎么判断？规则阈值和统计方法怎么选？
- 数据泄漏有哪些形式？为什么按时间切分有时比随机切分更合理？
- 类别不平衡怎么办？为什么只看 accuracy 危险？

### 模型相关

- 过拟合和欠拟合怎么判断？
- L1/L2 正则区别是什么？
- GBDT、XGBoost、LightGBM 区别和适用场景？
- 深度模型为什么可能在小数据上不如树模型？
- 学习率、batch size、epoch 分别影响什么？

### 指标相关

- AUC 的含义是什么？为什么不依赖固定阈值？
- F1 什么时候有意义？precision/recall 如何取舍？
- 推荐/搜索为什么看 NDCG/MAP/MRR？
- 离线指标提升，线上业务指标不涨，怎么解释？

### 工程相关

- 推理延迟高怎么定位？
- 特征线上线下不一致怎么办？
- 模型版本怎么管理和回滚？
- 数据漂移怎么监控？
- API 超时如何重试、降级和兜底？

### 场景题示例

```text
你在小厂做了一个分类模型，离线 F1 提升了，但上线后业务投诉误杀变多。你怎么排查？
```

回答要点：

- 先看 precision/recall 和阈值，不只看 F1。
- 分析误杀样例和业务成本。
- 检查线上数据分布是否变化。
- 按场景/人群分层评估。
- 临时回滚阈值或启用人工复核。

```text
推荐结果点击率下降，但模型和代码没变，可能原因是什么？
```

回答要点：

- 上游特征缺失或 schema 变化。
- 用户/内容分布变化。
- 节假日、活动、流量来源变化。
- 召回池质量下降。
- 日志埋点或指标口径变化。

## 回答防线

- 没有上线就不要写线上提升，写离线实验和上线验证方案。
- 没有真实大数据就写样本规模和可扩展方案。
- 指标必须有口径，不能只有“准确率提升”。
