# Role: 移动端 / 客户端

适用：Android、iOS、Flutter、React Native、小程序、客户端业务、离线缓存。

## 大厂看重点

- 能讲清页面生命周期、状态管理、网络请求、缓存、性能、崩溃和体验。
- 不只是写页面，要体现弱网、离线、权限、兼容性、包体积和监控。

## Toy 感

- 只写“完成页面开发”。
- 没有网络失败、空状态、权限、缓存。
- 没有性能、崩溃、兼容性处理。
- 没有埋点或日志。

## 可补强动作

半天：

- 梳理页面流和数据流。
- 补 loading、empty、error、retry 状态。
- 整理弱网、权限不足、数据为空、重复点击等 bad case。

1 天：

- 增加本地缓存或请求缓存。
- 增加防重复点击、权限检查、统一错误处理。
- 记录关键日志。

3 天：

- 做列表性能优化、图片懒加载、包体积分析。
- 加崩溃/异常监控。
- 做兼容性测试。

1 周：

- 做离线模式、增量同步或推送链路。
- 做埋点体系和用户行为分析。

## 简历表达素材

```text
参与 TODO 客户端模块开发，负责页面状态管理、网络请求封装和异常态处理；针对弱网、空数据、权限不足和重复点击等场景补充缓存、重试和兜底展示，提升业务流程可用性。
```
