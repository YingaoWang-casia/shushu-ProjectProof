## LLM / Agent

- 模型幻觉：答案编造、引用不存在、违反业务规则。
- 格式错误：JSON 解析失败、字段缺失、类型不一致。
- 工具调用失败：超时、限流、参数错误、权限不足。
- 多轮状态混乱：上下文污染、用户 session 错乱。
- Prompt 漂移：修改 prompt 后旧样例失败。
- 成本过高：token 过多、链路过长、重复调用。

## 后端 / 内部系统

- 脏输入导致 500。
- 重复提交导致重复记录。
- 权限校验缺失导致越权。
- 慢查询导致接口超时。
- 事务边界错误导致状态不一致。
- 缓存和数据库不一致。

## 前端

- 首屏慢、白屏、资源加载失败。
- 状态不同步、表单重复提交。
- 边界数据导致布局错乱。
- 权限菜单展示错误。
- 大表格卡顿、虚拟列表失效。
- 弱网/接口失败没有错误态。

## 算法 / 推荐 / 搜索

- 训练集和测试集泄漏。
- 指标提升但线上无感。
- 冷启动用户效果差。
- 长尾样本、极端 query 表现差。
- 离线/线上特征不一致。
- 模型推理延迟过高。

## 语音

- 噪声环境识别差。
- 口音、语速、重叠说话导致错误。
- VAD 截断开头或结尾。
- 流式延迟过高。
- TTS 音色不稳、停顿不自然。
- 音频采样率/格式不一致。

## 数据工程

- 字段缺失、重复、格式不统一。
- 上游 schema 变化导致静默错误。
- 数据延迟或重复消费。
- 质量报告缺失，无法对账。
- 规则堆叠不可维护。

## 追问方式

- 这个 bad case 是真实发生、你推测可能发生，还是准备补测？
- 有没有样例输入和错误输出？
- 你做的是修复、规避、人工兜底，还是记录为限制？
- 这个 case 能否作为面试证据？
