# 算法实习深挖题库

用于小厂算法/AI 实习冲大厂面试。按“项目细节 -> 算法基础 -> 场景题 -> 防线回答”组织。

## 数据与标签

必问：

1. 数据从哪里来？业务含义是什么？
2. 标签怎么生成？人工标注、规则生成、用户行为，还是历史结果？
3. 标签有没有延迟、噪声、偏差？
4. 数据量多大？正负样本比例是多少？
5. 训练/验证/测试怎么划分？按随机、时间，还是用户维度？
6. 有没有数据泄漏？比如同一用户、同一 query、同一商品同时进训练和测试？
7. 上游数据变更怎么发现？

八股补充：

- 类别不平衡怎么处理：重采样、class weight、focal loss、阈值调整、分层指标。
- 缺失值怎么处理：删除、填充、单独类别、模型内置处理、缺失指示特征。
- 异常值怎么处理：规则、截断、winsorize、robust scaler、人工复核。
- 数据泄漏常见来源：未来信息、重复样本、用户穿越、特征穿越、标准化在全量数据上 fit。

场景题：

```text
如果你的小厂数据只有几千条，面试官质疑样本太少，你怎么回答？
```

回答要点：

- 不夸大规模。
- 强调做了数据质量、bad case、baseline 和评估口径。
- 说明小数据下更重视交叉验证、人工复核、错误分析。
- 面向大厂会扩展到分层采样、自动标注、主动学习或在线反馈。

## 指标与评估

必问：

1. 为什么用 Accuracy/F1/AUC/Recall/NDCG/WER/CER？
2. precision 和 recall 冲突时怎么选？
3. AUC 的含义是什么？样本不平衡时是否可靠？
4. 推荐/搜索为什么看 NDCG、MAP、MRR？
5. 离线指标和线上指标为什么可能不一致？
6. 指标提升有没有显著性？有没有置信区间？
7. 没有线上 AB，简历怎么写？

八股补充：

- Accuracy：类别均衡时直观，不适合严重不平衡。
- Precision：预测为正里有多少真正。
- Recall：真正为正里找回多少。
- F1：precision/recall 调和平均。
- ROC-AUC：随机正样本排在负样本前的概率。
- PR-AUC：正样本稀少时更敏感。
- NDCG：考虑排序位置和相关性增益。
- WER/CER：语音识别字词错误率。

场景题：

```text
模型 A AUC 更高，但业务方更喜欢模型 B，为什么？
```

回答要点：

- AUC 是整体排序能力，不等价于业务阈值下收益。
- 模型 B 可能在高价值人群、topK、低延迟或稳定性上更好。
- 需要按业务分层、阈值、成本和线上反馈综合评估。

## Baseline 与实验

必问：

1. baseline 是什么？规则、传统 ML、深度模型还是已有系统？
2. 你改了什么？数据、特征、模型、loss、参数还是后处理？
3. 怎么证明提升来自你的改动？
4. 消融实验怎么设计？
5. 随机种子、环境、数据版本有没有记录？
6. 实验失败过吗？为什么？

八股补充：

- 过拟合：训练好、验证差；解决正则、dropout、早停、数据增强、简化模型。
- 欠拟合：训练和验证都差；解决更强模型、特征、训练更久。
- 正则化：L1 稀疏、L2 平滑权重。
- 交叉验证：小数据下减少划分偶然性。
- 超参数：学习率、batch size、epoch、树深、正则、阈值。

场景题：

```text
你做了三个改动，指标涨了，怎么知道哪个有效？
```

回答要点：

- 做控制变量和消融实验。
- 保持数据划分、随机种子、训练配置一致。
- 分别比较单改动和组合改动。
- 结合错误样例分析，不只看总指标。

## 特征工程

必问：

1. 你用了哪些特征？数值、类别、文本、图像、行为序列？
2. 类别特征怎么处理？
3. 连续特征为什么要归一化？
4. 高基数类别怎么处理？
5. 时间特征、统计特征是否有穿越？
6. 特征重要性怎么看？

八股补充：

- One-hot：简单但高维稀疏。
- Label encoding：可能引入虚假大小关系。
- Target encoding：有泄漏风险，需要交叉统计。
- Embedding：适合高基数类别或稀疏 ID。
- 标准化：对线性模型、距离模型、神经网络更重要。
- 树模型：对单调变换不敏感，但仍受异常值和类别编码影响。

场景题：

```text
一个特征离线很强，上线后效果差，可能为什么？
```

回答要点：

- 特征穿越或未来信息。
- 线上获取延迟或缺失。
- 训练/线上计算逻辑不一致。
- 分布漂移。
- 特征与业务目标短期相关但长期不稳。

## 模型选择

常见追问：

- 为什么用 LR/GBDT/XGBoost/LightGBM/深度模型？
- 小数据为什么不一定适合深度模型？
- 树模型和线性模型各自优缺点？
- Transformer 相比 RNN/CNN 强在哪里？
- BERT fine-tune 和 prompt 调用有什么区别？
- 什么时候规则比模型更适合？

回答要点：

- 小厂项目可以强调“简单可解释模型 + 错误分析 + 数据质量”。
- 不要为了高级而硬上深度模型。
- 模型选择要结合数据量、特征类型、延迟、可解释性、维护成本。

## 推荐 / 搜索专项

必问：

1. 召回、粗排、精排、重排分别做什么？
2. 负采样怎么做？
3. 冷启动怎么办？
4. 曝光偏差和位置偏差怎么处理？
5. 离线 NDCG 提升，线上 CTR 不涨怎么办？
6. 向量召回为什么快？ANN 有哪些思路？
7. 多目标排序怎么做？

场景题：

```text
新用户没有行为，推荐系统怎么做？
```

回答要点：

- 用热门、地域、上下文、注册信息、内容画像。
- 快速探索收集反馈。
- 引入多样性和冷启动策略。
- 不能只说“用协同过滤”。

## NLP / LLM 应用专项

必问：

1. 文本分类 bad case 有哪些？
2. prompt 改了怎么回归？
3. RAG 召回不准怎么办？
4. 模型幻觉怎么处理？
5. 为什么不 fine-tune？
6. embedding 怎么评估？
7. 结构化输出失败怎么办？

场景题：

```text
用户问了知识库没有的问题，模型一本正经胡说，怎么办？
```

回答要点：

- 检索置信度低时拒答。
- 答案必须带引用来源。
- 加事实一致性校验或规则校验。
- 记录 bad case，进入人工复核。

## CV 专项

必问：

1. 数据增强怎么做？为什么有效？
2. 分类、检测、分割指标分别是什么？
3. mAP 怎么理解？
4. 类别不平衡怎么处理？
5. 小目标、遮挡、光照变化怎么办？
6. 训练集效果好，实际图片效果差怎么办？

场景题：

```text
小厂业务图片很干净，大厂真实图片很脏，怎么办？
```

回答要点：

- 做数据增强、噪声模拟、域适配。
- 收集真实 bad case。
- 分场景评估，不只看总体指标。
- 设计人工复核和低置信度兜底。

## 语音专项

必问：

1. WER/CER 怎么算？
2. VAD 的作用是什么？
3. 噪声、口音、重叠说话怎么处理？
4. 流式识别延迟怎么评估？
5. 音频采样率不一致怎么办？

场景题：

```text
模型在安静环境识别很好，在电话录音里很差，怎么排查？
```

回答要点：

- 看采样率、编码、信噪比、口音、语速。
- 补降噪、VAD、数据增强。
- 分场景计算 CER/WER。
- 用 bad case 反馈迭代。

## 工程化追问

必问：

1. 模型怎么部署？API、批处理、离线任务？
2. 推理失败怎么办？
3. 模型版本怎么管理？
4. 特征版本怎么管理？
5. 日志记录哪些字段？
6. 数据漂移怎么监控？
7. 如何回滚？

场景题：

```text
线上模型效果突然变差，你怎么定位？
```

回答框架：

1. 先确认指标口径和监控是否异常。
2. 看输入数据分布、缺失率、schema 是否变化。
3. 看模型版本、特征版本、依赖服务是否变更。
4. 看分层指标，定位具体人群/场景。
5. 回滚旧版本或启用规则兜底。
6. 沉淀 bad case 和复盘。


弱表达：

```text
负责数据清洗。
```

```text
负责原始业务数据到可评估数据集的处理流程，设计字段标准化、缺失/重复/异常样本处理和抽样复核规则；输出数据质量报告和错误样例，为后续模型训练和指标评估提供可信数据基础。
```
