# 岗位细节追问与场景题

用于根据目标岗位补充“这个岗位常问的细节”。面试时不要机械背题，要把问题连回用户自己的项目。

## 大模型 / RAG

### 细节追问

1. 文档如何切分？chunk size 和 overlap 怎么选？
2. embedding 模型怎么选？中文、代码、表格分别有什么问题？
3. top_k 怎么设？召回太多和太少分别有什么影响？
4. rerank 的作用是什么？什么时候值得加？
5. 如何判断“知识库没有答案”？
6. 引用来源怎么做？如何防止模型编引用？
7. RAG 的评估集怎么构造？
8. token 成本和延迟怎么估算？
9. 权限隔离怎么做？不同用户能否看到不同文档？
10. 文档更新后索引如何增量更新？

### 八股转场

- 向量检索为什么快？ANN、HNSW、IVF 大概是什么思路？
- 余弦相似度、点积、欧氏距离区别是什么？
- BM25 和向量召回各自适合什么？
- 精确率和召回率如何用于检索评估？

### 场景题

```text
RAG 系统回答错误，怎么判断是召回错、重排错、prompt 错还是模型幻觉？
```

答题框架：

- 看 retrieved chunks 是否包含答案。
- 如果召回没有答案，排查切分、embedding、top_k、query rewrite。
- 如果召回有答案但生成错，排查 prompt、上下文顺序、引用约束。
- 如果引用错，增加引用校验和无依据拒答。
- 把 case 进入评估集。

## 大模型算法岗（预训练/对齐/微调/推理）

### 细节追问

1. Self-Attention 的计算公式和复杂度是什么？
2. Pre-LN 和 Post-LN 的训练稳定性差异是什么？
3. decoder-only 为什么更适合生成任务？
4. 你做的优化属于预训练、微调、对齐还是应用工程？
5. LoRA/QLoRA 的参数策略怎么选？
6. SFT、RLHF、DPO 的核心区别是什么？
7. 你如何识别 reward hacking 或过度拒答？
8. 推理侧如何定义 TTFT、TPOT、吞吐和 P95 延迟？
9. KV Cache 带来的加速和显存代价如何平衡？
10. 量化后质量退化怎么评估与控制？

### 场景题

```text
你做的 LoRA 在离线评测提升明显，但线上投诉增加，如何排查？
```

答题框架：

- 先确认评测集是否覆盖真实流量与边界场景。
- 分维度看：任务成功率、引用准确率、拒答率、毒性、安全策略触发率。
- 对比线上请求分布是否与离线样本分布一致。
- 分析是否出现过拟合、风格漂移或过度拒答。
- 回滚到稳定版本，补 bad case 与灰度策略。

## Agent 开发

### 细节追问

1. Agent 的工具列表是什么？每个工具的输入输出是什么？
2. 工具调用参数如何校验？
3. 工具失败、超时、限流如何处理？
4. 多轮对话状态怎么保存？如何避免跨用户污染？
5. planner、executor、verifier 是否拆开？
6. 哪些动作必须人工确认？
7. Agent 怎么做权限控制？
8. prompt 版本怎么管理？
9. bad case 如何回归？
10. 成本如何统计？

### 八股转场

- 状态机怎么设计？
- 重试为什么可能导致重复执行？幂等怎么做？
- 同步调用和异步任务怎么选？
- 队列积压怎么办？

### 场景题

```text
Agent 调用了一个会修改业务数据的工具，但模型参数生成错了，怎么办？
```

答题框架：

- 工具调用前做 schema 校验和业务规则校验。
- 高风险工具必须 human-in-the-loop。
- 每次调用记录 trace_id、参数、结果、操作者。
- 工具执行要支持幂等和回滚。
- 失败样例进入 bad case 回归集。

## 后端开发

### 细节追问

1. 表结构怎么设计？主键、索引、唯一约束是什么？
2. 事务边界在哪里？失败回滚怎么处理？
3. 幂等怎么做？唯一索引、幂等 token、状态机怎么选？
4. 缓存加在哪里？缓存一致性怎么保证？
5. 慢查询怎么定位？
6. 权限模型怎么设计？RBAC、资源级权限？
7. 日志记录什么字段？trace id 怎么串？
8. 接口错误码怎么设计？
9. 限流、熔断、降级分别解决什么？
10. 如果 QPS 提高 10 倍，瓶颈在哪里？

### 八股转场

- B+ 树索引为什么适合数据库？
- MVCC 是什么？
- Redis 缓存穿透、击穿、雪崩怎么处理？
- TCP 三次握手和四次挥手。
- 进程、线程、协程区别。

### 场景题

```text
接口偶发超时，日志只有少量 500，你怎么排查？
```

答题框架：

- 先用 trace_id 串联入口、服务、数据库、第三方。
- 看 p95/p99、慢查询、连接池、线程池、GC、下游超时。
- 临时加超时、重试、降级和限流。
- 长期补监控、告警、压测和容量评估。

## 前端开发

### 细节追问

1. 页面状态怎么管理？局部 state、全局 store、URL state 怎么分？
2. 表单校验在哪里做？前端校验和后端校验边界？
3. 接口失败如何展示？loading、empty、error、retry 是否完整？
4. 权限菜单和按钮权限怎么处理？
5. 大表格卡顿怎么优化？
6. 首屏加载慢怎么分析？
7. 组件怎么拆？如何避免过度封装？
8. 前端异常监控记录什么？
9. 埋点如何设计？
10. 如何做 E2E？

### 八股转场

- 浏览器渲染流程。
- 事件循环、宏任务、微任务。
- HTTP 缓存。
- React/Vue diff 大致原理。
- 防抖和节流区别。

### 场景题

```text
后台页面列表有 10 万条数据，滚动很卡，怎么办？
```

答题框架：

- 后端分页/游标分页，不能一次性全量渲染。
- 前端虚拟列表。
- 减少重复渲染，memo/computed。
- 图片/复杂组件懒加载。
- 加 loading、筛选、导出异步化。

## 语音 / 音频

### 细节追问

1. 音频采样率、声道、格式是什么？
2. VAD 的作用是什么？阈值怎么设？
3. WER/CER 怎么算？
4. 噪声、口音、快语速、重叠说话怎么处理？
5. 流式识别延迟怎么拆分？
6. ASR 后处理做了什么？
7. TTS 如何评估自然度？
8. 电话录音和近场麦克风有什么差别？
9. 音频切片会不会截断语义？
10. 语音 API 调用失败怎么兜底？

### 八股转场

- 傅里叶变换、梅尔频谱、MFCC 基本概念。
- WER/CER 和编辑距离。
- 流式和非流式区别。
- 降噪和回声消除基本目标。

### 场景题

```text
ASR 在 demo 音频上很好，在真实电话录音上很差，怎么办？
```

答题框架：

- 检查采样率、编码、信噪比、口音、语速、远近场差异。
- 分场景统计 CER/WER。
- 引入 VAD、降噪、数据增强或领域词表。
- 收集 bad case 做回归。

## 算法 / 推荐 / 搜索

### 细节追问

1. 数据怎么划分？有没有用户/时间维度泄漏？
2. baseline 是什么？为什么可信？
3. 指标和业务目标是否一致？
4. 误差主要来自哪些样本？
5. 消融实验怎么证明改动有效？
6. 线上推理延迟如何估算？
7. 负采样怎么做？
8. 冷启动怎么处理？
9. 特征线上线下是否一致？
10. 模型版本如何回滚？

### 八股转场

- 过拟合、欠拟合、正则化。
- AUC/F1/Recall/NDCG。
- GBDT/XGBoost/LightGBM。
- 召回/粗排/精排/重排。
- 数据泄漏和分布漂移。

### 场景题

```text
离线 AUC 涨了，但线上 CTR 掉了，怎么办？
```

答题框架：

- 检查离线样本和线上流量分布是否一致。
- 分层看新老用户、场景、时间段、长尾。
- 看是否优化了错误目标或引入偏差。
- 检查特征线上线下一致性。
- 回滚或灰度，补 AB 和监控。

### 细节追问

1. 数据源是什么？全量还是增量？
2. schema 怎么管理？
3. 数据质量指标有哪些？
4. 重复消费如何处理？
5. 任务失败如何重跑？
6. 数据延迟如何监控？
7. 上游字段变更如何报警？
8. 对账怎么做？

### 场景题

```text
昨天报表数据突然少了一半，怎么排查？
```

答题框架：

- 看上游数据量、任务日志、分区、过滤条件。
- 看 schema 变更和字段缺失。
- 看调度依赖是否失败。
- 与源表对账，定位丢失环节。

## 测试开发

### 细节追问

1. 用例怎么设计？覆盖核心路径还是边界路径？
2. mock 怎么做？
3. 自动化测试如何接入 CI？
4. flaky case 怎么处理？
5. 压测关注哪些指标？

### 场景题

```text
CI 偶现失败，本地无法复现，怎么办？
```

答题框架：

- 收集失败日志、随机种子、环境差异。
- 检查时间依赖、并发、外部服务、测试数据污染。
- 隔离 flaky case，增加重试和稳定性修复。

## 使用规则

当用户贴简历和 JD 后：

1. 先判断岗位方向。
2. 读取对应 role 文档和本文件相关章节。
3. 从用户项目中挑 3-5 个点，生成“项目追问 + 八股 + 场景题”的组合训练。
4. 每个问题都要求用户能回到自己的经历，不要只背概念。
