# Role: AIGC / Agent / RAG / MCP / 剪映类产品研发

适用：剪映、醒图、Faceu、内容创作工具、AIGC 应用、AI 生成链路编排、Prompt/RAG/MCP、图文/视频/音频多模态创作体验。

## 一、大厂真正看什么

这类岗位不是只看“会调大模型 API”，而是看能不能把 AI 能力编排进产品链路：

- 用户在什么创作场景触发 AI。
- 输入是什么：文本、图片、视频、音频、模板、历史素材。
- AI 链路怎么编排：理解、检索、规划、生成、校验、后处理、回填产品。
- 失败怎么处理：生成差、超时、违规、成本高、用户不满意。
- 如何和算法/产品协作：评估集、bad case、灰度、反馈闭环。
- 如何提升研发效率：工具化、Prompt 管理、MCP/tool schema、可观测性。

## 三、小厂项目常见低配点

- 只接一个 LLM API，没有工具调用 schema。
- 只有 Prompt，没有版本管理和 bad case 回归。
- 文档 RAG 不处理表格、跨页、目录、引用。
- 生成链路没有 trace_id，失败无法复现。
- 没有 latency、cost、token、重试、降级。
- 没有内容安全和人工审核。
- 没有和产品指标挂钩，只说“提升效率”。

## 四、剪映类场景高频追问

### AI 生成链路

1. 用户触发 AI 的入口在哪里？
2. 输入是文本、图片、视频、音频还是模板？
3. 生成结果如何回到编辑器？
4. 哪些步骤同步，哪些异步？
5. 超时后用户看到什么？

强回答要点：

- 把链路拆成 `输入理解 -> 工具/素材检索 -> 生成 -> 校验 -> 后处理 -> 回填产品`。
- 说明中间状态、失败兜底和人工/用户确认点。

### Prompt/RAG

1. Prompt 怎么版本管理？
2. RAG 召回错了怎么判断？
3. 如何防止模型编造引用？
4. 表格、图片、跨页内容怎么处理？
5. 无答案时怎么拒答？

强回答要点：

- 不说“感觉变好”，要说评估集、bad case、引用准确率和拒答准确率。

### MCP / Tool Calling

1. MCP 和普通 HTTP tool call 区别是什么？
2. 工具 schema 怎么定义？
3. 工具调用权限怎么控制？
4. 参数错了怎么办？
5. 高风险工具是否需要人工确认？

强回答要点：

- 如果没做 MCP，承认边界：做过 HTTP 工具链/工作流，理解 MCP 的工具暴露、schema、权限和上下文协议，补过最小 demo 才能写。

### 性能与稳定性

1. 整条 AI 链路 p95 延迟是多少？
2. 哪个节点最慢？
3. 模型 API 超时怎么办？
4. 并发请求怎么处理？
5. token 成本怎么统计？

强回答要点：

- 按节点拆耗时：检索、rerank、生成、后处理。
- 说明缓存、异步、降级、重试退避和用户可感知反馈。

### 多模态内容

1. 图片/视频/音频 metadata 怎么保留？
2. 生成结果低质量怎么办？
3. 内容安全如何做？
4. 用户不满意如何反馈到优化？
5. 实时交互和长任务生成怎么取舍？

强回答要点：

- 不把“图片检索”说成“多模态生成模型优化”。
- 可以说理解创作链路中的素材检索、生成结果校验、用户反馈和人工审核。

## 五、可补做的高价值证据

半天：

- 画 AI 生成链路 DAG。
- 整理 10 个生成/RAG/Agent bad case。
- 列出每个节点输入、输出、失败类型。

1 天：

- 加 trace_id 日志字段设计。
- 做 Prompt 版本表。
- 做 30 条 query-answer-evidence 评估集。

3 天：

- 做最小 MCP demo：`document_search`、`rerank`、`draft_generate`、`image_retrieve`。
- 统计节点耗时和模型调用成本。
- 写一份质量报告：召回命中、引用准确、拒答、延迟。

1 周：

- 做一个可演示的 Agent 任务看板。
- 支持 human-in-the-loop 审核状态。
- 补混合检索和 rerank 对比。
